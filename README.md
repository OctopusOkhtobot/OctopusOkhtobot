# Okhtobot

من درعا، سوريا. أبني تطبيقات ويب وألعابًا صغيرة: زراعة، خدمات محلية، وتجارب بصرية.

هذه الصفحة تجمع المشاريع المنشورة في مكان واحد، بدل قائمة طويلة بلا ترتيب.

## أعمال

| المشروع | ماذا يفعل | افتحه |
|---|---|---|
| البوابة الإلكترونية لكهرباء سوريا | مشروع تخرج — بوابة المؤسسة العامة لكهرباء سوريا | [الموقع](https://octopusokhtobot.github.io/syria-electricity-portal/) · [الكود](https://github.com/OctopusOkhtobot/syria-electricity-portal) |
| عيادة أسنان مبسطة | واجهة عيادة صغيرة | [الموقع](https://octopusokhtobot.github.io/sann/) · [الكود](https://github.com/OctopusOkhtobot/sann) |
| عداد العملة السورية | عدّ الأوراق باستخدام YOLO | [الكود](https://github.com/OctopusOkhtobot/syrian-currency-counter) |

## زراعة

سلسلة تجارب حول الزيتون والبيوت البلاستيكية وأمراض النبات.

| المشروع | الفكرة | افتحه |
|---|---|---|
| لعبة الزيتون | ازرع أنواعًا مختلفة واكسب نقاطًا | [الموقع](https://octopusokhtobot.github.io/game-of-OLIVE-/) |
| grokolive | لعبة زيتون بأسلوب مختلف | [الموقع](https://octopusokhtobot.github.io/grokolive/) |
| game-by-grok4.5 | نسخة أخرى من لعبة الزيتون | [الموقع](https://octopusokhtobot.github.io/game-by-grok4.5/) |
| زراعة الطيبة | تطبيق زراعة | [الموقع](https://octopusokhtobot.github.io/zraaa-Altaiba/) |
| Zetton | الزيتون داخل البيوت البلاستيكية | [الموقع](https://octopusokhtobot.github.io/Zetton/) |
| تقليم الزيتون | إعداد عقل وغراس جديدة | [الموقع](https://octopusokhtobot.github.io/Olive-/) |
| بيتي البلاستيكي | ملف صغير لعقل الزيتون | [الموقع](https://octopusokhtobot.github.io/-mygreenhouse/) |
| تشخيص أمراض النبات | التعرّف على أمراض النبات | [الموقع](https://octopusokhtobot.github.io/zera2a/) |
